<p>Este es un proyecto sobre una gestión de clientes con las acciones de agregar, buscar y eliminar un cliente realizado con el framework Springboot. Con ayuda de una base de datos con el entorno <b>MySql Workbench.</b></p>
<ol>
  <li>Ir al entorno sql y crear la base de datos: bdclientes</li>
  <li>Ir a <b>resources</b> y luego a <b>application.properties.</b></li>
  <li>En <b>application.properties</b> cambiar el nombre de usuario (si es necesario, en mi caso está en root), también cambiar contraseña.</li>
  <li>Cambiar puerto también (si es necesario).</li>
  <li>Finalmente ejecutar el programa en <b>DemoAplication.java</b></li>
  <li>Ir al navegardor y colocar <b>localhost:(puerto)/inicio</b></li>
</ol>
<br>
<p>Este programa lo realicé en lenguaje java y como mencioné con anterioridad, también usé el framework Springboot.</p>
